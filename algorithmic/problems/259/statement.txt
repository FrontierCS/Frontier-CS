# Sum of Two Numbers

## Problem
Given two integers A and B, compute their sum.

## Input Format
- Line 1: Two space-separated integers A and B (-10^9 ≤ A, B ≤ 10^9)

## Output Format
- Line 1: A single integer, the sum A + B

## Example

Input:
```
3 5
```

Output:
```
8
```

## Constraints
- -10^9 ≤ A, B ≤ 10^9

## Scoring
- 100 points for correct answer
