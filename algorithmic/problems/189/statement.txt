# Common-Subsequence Alignment Challenge

## Objective
You are given two strings S1 and S2. Output an alignment transcript that maximizes the number K of equal-character matches. The matched characters form a common subsequence. The strings can be very large, so approximate alignments are accepted.

## Input Format

The input consists of two lines.

1. The first line contains the string S1.
2. The second line contains the string S2.

The strings contain only uppercase English characters ('A'-'Z') and digits ('0'-'9').

## Output Format
Output one line containing a transcript T consisting only of M, D, and I:

- M consumes one character from each string; it contributes one match when those characters are equal, and zero otherwise.
- D consumes one character from S1 and contributes zero matches.
- I consumes one character from S2 and contributes zero matches.

Start at the first character of both strings. The transcript must consume both strings completely, without reading past either end. Thus the number of M plus D operations equals |S1|, and the number of M plus I operations equals |S2|. Invalid transcripts receive zero.

## Scoring

The physical objective is aligned common subsequence length K; larger is better. The physical reference is `a = R`; matching a positive reference earns 60 points.

R is the stored reference LCS/alignment length.

Define the historical low-score expression (in points):

    P_low = 60*K/R.

If `P_low<=60`, retain `max(0,P_low)`. For `P_low>60` and a positive physical reference and objective, award:

    r = K / a
    P = min(100, 60 + ln(r)).

Here `r` is the improvement factor relative to the physical reference, and `ln` is the natural logarithm with coefficient 1. In the uncapped upper branch, `r = exp(P-60)`: each additional point means an `exp(1)`-fold improvement in the physical objective. The factor is computed from the physical objective and its reference, not from a transformed reward or the old point score. Invalid output retains its existing rejection or zero score; the zero-cost exception applies only after validation. Use one score per file. Both reported ratio channels use points divided by 100. Across official files, take the arithmetic mean.

If R=0 and the strings have no common character, the exact empty case retains 100 points; a zero reference with a shared character is a data error.

## Example
Input:
KITTEN
SITTING

Output:
MMMMMMI

This transcript consumes both strings. The four equal-character matches are I, T, T, and N, so K=4. If the stored reference count is R=4, this earns60 points.

## Constraints

- 1 <= |S1|, |S2| <= 10,000,000 (1e7)
- Character Set: [A-Z, 0-9]
- Time Limit: 3.0s
- Memory Limit: 512MB
