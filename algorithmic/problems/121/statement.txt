DNA Matching

Time Limit: 2 s
Memory Limit: 512 MB

A string s is called a “DNA sequence” if and only if s consists only of the characters A, C, G, T.

You are given m strings s1, s2, ..., sm, each of length n, and each of them consists only of the characters A, C, G, T, ?.

For a DNA sequence t of length n, we call t valid if and only if there exists an index i (1 ≤ i ≤ m) and a way to replace each ? in si by one of A,C,G,T, so that after replacement the resulting string s_i' is exactly equal to t.

You need to compute the probability that a randomly chosen DNA sequence t (of length n, where each of the 4^n possible DNA sequences is equally likely) is valid.

Input Format
The first line contains two positive integers n, m.
Then follow m lines, each line contains a string si of length n. It is guaranteed that each si only uses characters from A, C, G, T, ?.

Output Format
Output one real number — the probability. Make sure the number is precise enough.

Sample 1
input
3 1
AC?
output
0.0625

Sample 2
input
6 2
AC??A?
A??A?T
output
0.0302734375

## Scoring

All feasibility and interaction limits apply before scoring; invalid output receives zero. Points are averaged over test files. For the logarithmic branch, write x for the original minimizing quantity and a for its physical 60-point reference. The improvement factor is r=a/x, and the upper-band award is P=min(100,60+ln(r)). Here ln is natural: r=1 corresponds to 60 points, and on the uncapped logarithmic upper band, r=exp(P-60). Each additional point multiplies the physical improvement factor by e (divides a minimizing objective by e or multiplies a maximizing objective by e, as applicable). The lower-band, zero-objective, and completion rules below still apply.

p is the output probability and p_ref is the stored reference probability. When p_ref is nonzero, E=abs(p/p_ref-1). Define the objective x=E, its physical reference a=A=0.04, and the lower-band calculation L=100*max(0,1-10*E).

If p_ref=0, output p=0 receives 100 and every nonzero p receives zero; the following rule applies only when p_ref is nonzero.

```text
P = 100,                         if x = 0
P = L,                           if L <= 60 and x > 0
P = min(100, 60 + ln(r)),      otherwise
```

Zero is tested on the valid original count, cost, or error, before the lower-band test. A zero reference anchor has no positive improvement branch; positive objectives keep their lower-band score. Zero error means equality to the stored floating-point reference; do not infer zero from rounded awarded points. The checker reports P/100.
