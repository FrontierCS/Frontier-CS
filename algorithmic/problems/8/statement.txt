The Empress

Capoo invented an interesting language named Push-Pop. This language is an interpreted language. The interpreter starts with an empty stack with infinite capacity and reads the first instruction of the custom program. There are only two kinds of instructions in this language:

POP a GOTO x PUSH b GOTO y

If the top element of the stack is a, then pop the stack once and transfer the control flow to the x-th instruction (which means the next instruction will be the x-th).

Otherwise, push an element b into the stack and transfer the control flow to the y-th instruction.

HALT PUSH b GOTO y

If the stack is empty, halt the whole program after executing this instruction. Otherwise, push an element b into the stack and transfer the control flow to the y-th instruction. Capoo wants to construct a Push-Pop program that halts after executing exactly k instructions. A program can contain at most 512 instructions. Use as few program instructions as possible; points are defined in Scoring.

Input

The only line contains a single integer k (1 <= k <= 2^31 − 1, k is odd).

Output

The first line contains an integer n (1 <= n <= 512) denoting the number of instructions, and then follows n lines denoting the Push-Pop program. For each instruction, 1 <= a, b ≤ 1024, 1 <= x, y <= n should hold. It is guaranteed that a solution exists for given input.

Example Input 1:

1

Example Output 1:

1
HALT PUSH 1 GOTO 1

Example Input 2:

5

Example Output 2:

5
POP 1 GOTO 2 PUSH 1 GOTO 2
HALT PUSH 1 GOTO 3
POP 1 GOTO 4 PUSH 2 GOTO 4
POP 1 GOTO 2 PUSH 2 GOTO 4
HALT PUSH 99 GOTO 4

## Scoring

Let x be n, the program instruction count. The physical reference (the 60-point level) is a=204.8. Define the lower-band continuation:

    L(x) = 100*max(0,min(1,1-x/512)).

For positive x and positive physical reference a, define the improvement factor r=a/x. The physical reference has r=1 and earns 60 points. For a valid output on this branch, the points P are:

    P = 100,                          if x=0;
    P = L(x),                         if L(x)<=60;
    P = min(100,60+ln(r)),             otherwise.

Here ln is the natural logarithm. In the upper branch before the 100-point cap, r=exp(P-60): each additional point requires an e-fold improvement in the physical objective (division by e). All feasibility, correctness, and hard resource-limit checks remain required; invalid output receives 0.

Across test files, use the arithmetic mean of the file scores.
