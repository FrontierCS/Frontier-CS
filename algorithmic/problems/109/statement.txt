Time Limit: 1 second
Memory Limit: 128 MB

Description
A knight moves on an N×N chessboard and must try to visit every square exactly once (no revisiting). Given the board size and the starting square, output the longest possible path.
Note that this problem doesn't require a full complete path. It only asks you to find the longest path possible, and output that path.

Constraints
- 6 ≤ N ≤ 666

Input
- The first line contains the integer N.
- The second line contains two integers r c — the starting position (row and column), 1-indexed.

Output
- The first line of output should be an integer l: the length of the path you found(remember to include r0, c0)
- Then output l lines. Each line must contain two integers r c (1-indexed), the successive positions visited by the knight, starting with the given starting position.
When outputting the answer, make sure to not have an extra empty line at the end of the output after printing out the final move.
- The first pair of coordinates in your path must be the starting points r0 and c0.

## Scoring

All feasibility and interaction limits apply before scoring; invalid output receives zero. Points are averaged over test files. For the logarithmic branch, write x for the original maximizing quantity or quality and a for its physical 60-point reference. The improvement factor is r=x/a, and the upper-band award is P=min(100,60+ln(r)). Here ln is natural: r=1 corresponds to 60 points, and on the uncapped logarithmic upper band, r=exp(P-60). Each additional point multiplies the physical improvement factor by e (divides a minimizing objective by e or multiplies a maximizing objective by e, as applicable). The lower-band, zero-objective, and completion rules below still apply.

X is the number of squares in the valid knight path, including its start, and R>0 is the stored reference path length. Define the objective x=X, its physical reference a=A=R, and the lower-band calculation L=60*X/R.

```text
P = L,                           if L <= 60
P = min(100, 60 + ln(r)),      otherwise
```

Zero value of a maximizing objective is not a perfect solution and earns no special full-score award. The checker reports P/100.
