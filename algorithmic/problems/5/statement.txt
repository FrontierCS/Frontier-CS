Hamiltonian Path Challenge

Given a directed graph with n vertices and m edges, find a path visiting as
many distinct vertices as possible. Vertices may not be repeated. Every
consecutive pair must be a directed edge in the graph.

Input
The first line contains n and m.
The second line contains ten legacy integers. Read and ignore this line:
these values no longer define subtasks or affect scoring.
Each of the next m lines contains u v, representing the edge u -> v.

Output
Print the number k of vertices in your path, followed by the k vertex indices.
An empty path (k=0) is valid and receives zero points.

## Scoring

Let x be k, the number of vertices in the submitted path. R is the number of vertices in the comparison path stored with the test. The ten legacy input thresholds do not affect scoring. The physical reference (the 60-point level) is a=R. Define the lower-band continuation:

    L(x) = 60*x/R.

For positive x and positive physical reference a, define the improvement factor r=x/a. The physical reference has r=1 and earns 60 points. For a valid output on this branch, the points P are:

    P = L(x),                         if L(x)<=60;
    P = min(100,60+ln(r)),             otherwise.

Here ln is the natural logarithm. In the upper branch before the 100-point cap, r=exp(P-60): each additional point requires an e-fold improvement in the physical objective (multiplication by e). A zero maximization objective is not a full-score exception. All feasibility, correctness, and hard resource-limit checks remain required; invalid output receives 0.

Across test files, use the arithmetic mean of the file scores.


Example
Input:
3 3
3 3 3 3 3 3 3 3 3 3
1 2
1 3
2 3

Output:
3
1 2 3

This visits all three vertices. If the reference path has length 3, it earns
60 points.

Constraints
1 <= n,m <= 500000.
No multiple edges or self-loops.
At least one Hamiltonian path exists in the graph.
Time limit: 4 seconds. Memory limit: 512 MB.
