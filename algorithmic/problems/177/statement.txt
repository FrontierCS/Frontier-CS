# Graph 3-Coloring

## Problem

You are given an undirected graph with n vertices and m edges.
Your task is to assign each vertex one of three colors.

The objective is to minimize the number of conflicting edges.
An edge is conflicting if its two endpoints have the same color.

## Input Format

- Line 1: two integers n and m (1 ≤ n ≤ 60000, 0 ≤ m ≤ 200000)
- Next m lines: two integers u v (1 ≤ u, v ≤ n, u ≠ v)
The graph may be disconnected.
There are no multiple edges or self-loops.

## Output Format

- Output exactly one line:
  - n integers c₁ c₂ … cₙ
  - each cᵢ ∈ {1, 2, 3}

## Scoring

The physical objective is same-color edge count b; smaller is better. The physical reference is `a = 0.4*m`; matching a positive reference earns 60 points.

Here m is the total number of graph edges.

Define the historical low-score expression (in points):

    P_low = 100*(1-b/m).

A valid solution with `b=0` receives 100 points, including a zero-baseline instance. Otherwise, if `P_low<=60`, retain `max(0,P_low)`. For `P_low>60` and a positive physical reference, award:

    r = a / b
    P = min(100, 60 + ln(r)).

Here `r` is the improvement factor relative to the physical reference, and `ln` is the natural logarithm with coefficient 1. In the uncapped upper branch, `r = exp(P-60)`: each additional point means an `exp(1)`-fold improvement in the physical objective. The factor is computed from the physical objective and its reference, not from a transformed reward or the old point score. Invalid output retains its existing rejection or zero score; the zero-cost exception applies only after validation. Use one score per file. Both reported ratio channels use points divided by 100. Across official files, take the arithmetic mean.
