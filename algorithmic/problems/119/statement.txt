Operators

-   You are given n operators op₁, op₂, …, opₙ. For an input sequence of
    n+1 integers a₀, a₁, …, aₙ, you need to compute the following value:
    (((…(a₀ op₁ a₁) op₂ a₂) op₃ a₃)… opₙ aₙ) mod (10⁹ + 7).
-   For any 0 ≤ i ≤ n, we have 0 ≤ aᵢ < 10⁹ + 7.
-   For any 1 ≤ i ≤ n, opᵢ ∈ {+, ×}; that is, each operator is either
    addition “+” or multiplication “×”.

You quickly wrote a program to solve this problem. Unfortunately,
because you were over‑excited after solving it, you accidentally deleted
the original problem statement and your code. As a result, you lost the
information about the n operators op₁, …, opₙ. Fortunately, you still
have the program you just compiled, so you can recover these operators
by querying your program.

Since the contest is about to end, and the program you wrote is not
efficient enough, you cannot ask more than Qₘₐₓ = 600 queries.

Implementation details

This is an interactive problem. As usual, you should submit a source code file that can compile.

Initially, you should read an integer n, the number of operators.

You may issue queries by writing to standard output lines of the form

? a₀ a₁ … aₙ

1 <= a_i < 10^9+7

Then you must flush output, and read from standard input one integer in [0, 10⁹ + 6], representing the interactor’s response.

When you have determined the operators, output a line of the form

! o₁ o₂ … oₙ

o_i is 0 if op_i is "+", is 1 if op_i is "×".

Remember to flush after your output.

Subtasks

-   For all data, 1 ≤ n ≤ 600.
-   Exceeding a time, memory, or query limit, or returning an incorrect answer, receives zero.

## Scoring

All feasibility and interaction limits apply before scoring; invalid output receives zero. Points are averaged over test files. For the logarithmic branch, write x for the original minimizing quantity and a for its physical 60-point reference. The improvement factor is r=a/x, and the upper-band award is P=min(100,60+ln(r)). Here ln is natural: r=1 corresponds to 60 points, and on the uncapped logarithmic upper band, r=exp(P-60). Each additional point multiplies the physical improvement factor by e (divides a minimizing objective by e or multiplies a maximizing objective by e, as applicable). The lower-band, zero-objective, and completion rules below still apply.

Q is the number of queries. Define the objective x=Q, its physical reference a=A=40, and the lower-band calculation L=60*41/(Q+1).

```text
P = 100,                         if x = 0
P = L,                           if L <= 60 and x > 0
P = min(100, 60 + ln(r)),      otherwise
```

Zero is tested on the valid original count, cost, or error, before the lower-band test. A zero reference anchor has no positive improvement branch; positive objectives keep their lower-band score. The +1 shift is used only in L, not in the logarithm. The checker reports P/100.
